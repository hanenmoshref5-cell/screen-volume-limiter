# حدّ الصوت للشاشة — Screen Volume Limiter

<div dir="rtl">

نظامٌ مؤلَّف من **تطبيقين** يعملان معاً عبر الشبكة المحلية لتحديد **الحدّ الأقصى لمستوى الصوت** على شاشة LG الذكية (webOS)، ثم فرضِ هذا الحدّ تلقائياً دون تدخّل من أي مستخدم:

| التطبيق | المنصة | الاسم | الدور |
|---|---|---|---|
| تطبيق التحكّم | هاتف أندرويد (Flutter) | **صوت الشاشة** | إدخال القيمة القصوى (0–100) وإرسالها إلى الشاشة |
| تطبيق الشاشة | LG webOS | **شاهد** | استقبال القيمة وحفظها وفرضها في الخلفية |

## فكرة المشروع

يتيح المشروع لوليّ الأمر أو مدير الشاشة تحديد سقفٍ للصوت (مثلاً 20 من 100) من هاتفه. وما إن تُرسَل القيمة حتى تتولى الشاشة خفض الصوت تلقائياً كلما حاول أحدٌ رفعه فوق السقف، سواء من الريموت أو من أي مصدر آخر.

### تطبيق الشاشة «شاهد»

صُمِّم كأداة رقابة أبوية منزلية بواجهة بسيطة تعرض الشعار فقط، أما عمله الفعلي فيجري في خدمة خلفية لا تقاطع استخدام الشاشة.

## آلية العمل

```
┌──────────────────┐   HTTP POST /volume-cap   ┌───────────────────────────┐
│  هاتف أندرويد     │ ────────────────────────▶ │   شاشة LG (webOS)          │
│  «صوت الشاشة»    │      {"value": 20}        │   خدمة «شاهد» الخلفية      │
│  (Flutter)       │ ◀──────────────────────── │   • تحفظ القيمة            │
└──────────────────┘        نجاح / فشل         │   • تراقب مستوى الصوت      │
                                               │   • تخفضه عند تجاوز السقف  │
                                               └───────────────────────────┘
```

1. يُدخل المستخدم القيمة على الهاتف ويضغط «إرسال».
2. يرسلها التطبيق إلى خادم HTTP صغير داخل خدمة الشاشة (المنفذ `57100`).
3. تحفظ الخدمة القيمة بشكل دائم، وتراقب مستوى الصوت عبر ناقل `luna://com.webos.audio`.
4. إذا تجاوز الصوت السقف أعادته الخدمة إليه فوراً.

## أبرز المزايا

**تطبيق الهاتف**
- شريط تمرير من 0 إلى 100 وزر إرسال، وواجهة عربية من اليمين إلى اليسار.
- رسائل واضحة للنجاح أو الفشل مع بيان السبب.
- حفظ **آخر قيمة أُرسلت** محلياً وعرضها عند فتح التطبيق.
- **اكتشاف الشاشة تلقائياً**: إذا تغيّر عنوان IP للشاشة يمسح التطبيق الشبكة المحلية ويجدها ويحفظ العنوان الجديد.

**تطبيق الشاشة**
- **يبدأ تلقائياً بعد كل إعادة تشغيل** (خلال نحو 16 ثانية) دون الحاجة إلى فتح التطبيق.
- **يتذكّر آخر قيمة** حتى بعد انقطاع الكهرباء أو إعادة تثبيت التطبيق (تُحفظ في قاعدة بيانات webOS وفي ملفات متعددة).
- خدمة خلفية مكتوبة بـ ES5 لتعمل على إصدارات webOS القديمة.
- منفذ UDP (`57099`) اختياري للاكتشاف على الشبكة المحلية.

## التثبيت (ملخّص)

الشرح الكامل للمبتدئين في [docs/LG-Install-Guide.pdf](docs/LG-Install-Guide.pdf). باختصار:

**على الشاشة:** ثبّت تطبيق *Developer Mode* من متجر LG، وفعّله مع *Key Server*، ودوّن عنوان IP والـ Passphrase.

**على الحاسوب:**
```bash
npm install -g @webos-tools/cli
ares-setup-device --add lgtv -i "host=<TV_IP>" -i "port=9922" -i "username=prisoner" -i "profile=tv"
ares-novacom --device lgtv --getkey

cd tv-app
ares-package shahid-app
ares-install --device lgtv com.home.shahid_1.0.0_all.ipk
ares-launch --device lgtv com.home.shahid
```

**على الهاتف:**
```bash
cd mobile-app
flutter pub get
flutter build apk --release
adb install -r build/app/outputs/flutter-apk/app-release.apk
```

## واجهة الخدمة (HTTP)

| الطريقة | المسار | الوصف |
|---|---|---|
| `GET` | `/ping` | التحقق من عمل الخدمة وقراءة القيمة الحالية |
| `GET` | `/status` | معلومات تشخيصية |
| `POST` | `/volume-cap` | ضبط الحدّ الأقصى، والجسم: `{"value": 0-100}` |

## ملاحظات وقيود

- يجب أن يكون الهاتف والشاشة على **الشبكة المحلية نفسها**.
- تُثبَّت التطبيقات عبر *Developer Mode*، وهي تُحذف إذا أُطفئ هذا الوضع أو انتهت مدة الجلسة؛ لذا يُضغط **EXTEND** دورياً (نحو مرة كل شهر).
- الاتصال بين الهاتف والشاشة غير مشفّر ولا يتطلب مصادقة، فهو مخصّص للاستخدام داخل شبكة منزلية موثوقة.
